Periféricos de PC são dispositivos externos que se conectam ao computador para enviar ou receber informações. Entrada: Enviam dados para o computador. Exemplos: teclado, mouse e microfone. Saída: Mostram dados processados pelo computador. Exemplos: monitor e caixas de som.
